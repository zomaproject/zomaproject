## Cómo trabajo

- 📏 **La arquitectura se ajusta al tamaño del problema.** Vertical Slice para empezar; módulos y capas cuando el negocio los pide.
- 📜 **El contrato es OpenAPI.** El frontend genera sus tipos del backend; ningún tipo de API se escribe dos veces.
- 🧪 **Pruebas contra infraestructura real**, más pruebas de arquitectura que protegen los límites entre módulos.
- ☁️ **Infraestructura como código.** Todo lo de AWS vive en Terraform; nada se crea a mano en la consola.
- 📝 **Decisiones documentadas.** Specs, contratos y diferencias con producción quedan escritos junto al código.
