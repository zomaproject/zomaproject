## Sobre mí

Construyo aplicaciones web de punta a punta: APIs en **.NET** con EF Core, interfaces en **React** con TypeScript e infraestructura en **AWS** definida con **Terraform**.

- 🧱 Arquitectura a la medida del problema: Vertical Slice para lo simple, capas cuando el negocio lo pide.
- 📜 Contrato primero: OpenAPI genera los tipos del frontend, nada se escribe dos veces.
- ✅ Pruebas de integración con bases de datos reales (xUnit + Testcontainers).
